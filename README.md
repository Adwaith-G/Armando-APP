# Armando Muscle Club — GitHub Pages website

A responsive, static website containing:

- `index.html` — app introduction and links to legal pages
- `privacy-policy.html` — complete app Privacy Policy
- `terms-and-conditions.html` — complete app Terms & Conditions
- `assets/style.css` — site styling (no external scripts, fonts or analytics)
- `assets/logo.png` — existing app logo
- `assets/app-icon.png` — matching existing Play Store icon
- `.nojekyll` — serves the files as plain static HTML

**Legal text:** The two policy pages preserve the text of the Privacy Policy and Terms & Conditions packaged in `ArmandoMuscleClub-PlayStore-PolicyReady.zip` (effective 17 November 2026). Please personally verify that each data-handling claim is still accurate in the final build. Policies are legal documents and this template does not guarantee Google Play acceptance.

## Upload to GitHub (Malayalam / മലയാളം)

1. https://github.com/new തുറക്കുക; login ചെയ്യുക.
2. **Repository name:** `armando-muscle-club` എന്നാക്കുക. **Public** തിരഞ്ഞെടുക്കുക; **Create repository** അമർത്തുക.
3. Repository-യിൽ **Add file → Upload files** തുറക്കുക. ഈ ZIP unzip ചെയ്തതിനുശേഷമുള്ള **എല്ലാ files/folders** upload ചെയ്യുക. `index.html` repository-യുടെ root-ൽ വേണം; extra folder level ഉണ്ടാകരുത്.
4. **Commit changes** ചെയ്യുക.
5. Repository → **Settings → Pages** തുറന്ന് **Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save** തിരഞ്ഞെടുക്കുക.
6. GitHub Pages website publish ആയശേഷം താഴെ കൊടുത്ത URLs browser-ൽ തുറന്ന് **mobile, desktop** രണ്ടിലും പരിശോധിക്കുക.
7. Privacy Policy URL Google Play Console-ലെ **App content → Privacy policy** field-ൽ നൽകുക. App-ലും Privacy Policy link/text ലഭ്യമായിരിക്കണം (ഇപ്പോൾ project-ൽ offline copy ഉണ്ട്).

## Verify before Play Console submission

- Test both policy links in an incognito/private browser. They must be reachable worldwide without login.
- Ensure the Privacy Policy accurately reflects the released app: device-stored fitness/health entries, optional exercise-image requests to GitHub, external enquiry actions, permissions, manual text backup, and deletion steps. Reconcile any changes with the in-app copy and Google Play Data safety form.
- Verify the visible developer/contact email `adwaithcontact@gmail.com` is yours and suitable for public display; if not, replace everywhere on the website and inside the app.
- The app project contains third-party/image build dependencies and a separate release checklist. Publishing the website does not publish or approve the Android app.
